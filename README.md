# 測定ライセンス(APS)会員サイト+管理画面 — 本番用フロントエンド

アスレティックパフォーマンスサイエンティスト(APS)資格のeラーニングサイトです。
単一の `index.html` に会員サイトと運営用管理画面の両方を含みます(外部依存はGoogle Fontsのみ)。

## ログイン(共通ログイン画面)

メールアドレスで会員/管理者を自動判定します。

| 区分 | 入り方 |
|---|---|
| 会員 | 「入会申し込み」から登録(プラン選択→決済記録)。以後は登録したメール+パスワードでログイン |
| 管理者 | `admin@s-cade.jp` / `aps-admin-2026` でログイン → 二要素認証(デモ:任意の6桁)→ 管理画面へ |

## 実装状況

**実際に動作する処理(ブラウザのlocalStorageに永続化・リロード後も保持)**
- 会員登録(パスワードはSHA-256ハッシュで保存)/ログイン/ログアウト/退会(データ削除)
- プラン購入記録と受講・受験権限(受講+受験/受講のみ/受験のみ)
- レッスンの実時間再生・しおり・視聴80%での完了記録・章別進捗・サイドバッジ
- 認定試験の解放条件(受験権限+全レッスン完了)・採点・受験履歴・認定番号の採番・認定証表示
- B級講座のロック(C級取得後に解放)
- セミナー申込→支払い履歴→請求書/領収書(インボイス様式)
- お知らせの既読管理・会員情報の変更

**バックエンド接続時に差し替えるポイント(コード内にコメントあり)**
- Stripe Checkout / Webhook による実決済(現在は決済成功を記録するのみ)
- 動画配信基盤(Vimeo / Cloudflare Stream)の実プレイヤー
- 認定番号のサーバー側採番、資格確認ページ、メール送信
- 管理者認証(現在はデモ用にフロントに資格情報あり。**本番前に必ずサーバー認証+IP制限へ移行**)
- 管理画面のデータ(受講者・売上等)は現在サンプルデータ表示

## GitHub Pages での公開手順

1. このフォルダの内容をリポジトリのルートに push(`index.html` が直下)
2. リポジトリの **Settings → Pages → Deploy from a branch → main / (root)** で Save
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開

※ `.nojekyll` はそのまま置いてください。
※ 進捗データは閲覧者それぞれのブラウザに保存されます(サーバーには何も送信されません)。
