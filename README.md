# 測定ライセンス(APS)ユーザーサイト — プロトタイプ

アスレティックパフォーマンスサイエンティスト(APS)資格のeラーニング会員サイトのプロトタイプです。
単一の `index.html` で完結する静的サイトで、外部依存はGoogle Fonts(Noto Sans JP)のみです。

> **注意** 本サイトはデモです。受講者データ・試験問題・決済・認定証はすべてモックで、
> 入力内容は保存されません。ログイン画面は任意の入力で進めます。

## 内容

- 会員登録/ログイン/パスワード再設定(デモ)
- C級講座(全18レッスン・全5章)・B級講座(全19レッスン)の動画受講UI・進捗管理
- 認定試験(100問・60分・合格70%/カメラスナップショット・操作ログのデモ)
- 資格・認定証(氏名差し込み・SNSシェア)
- 支払い・請求(Stripe想定・請求書/領収書のインボイス対応帳票)
- セミナー・お知らせ・会員情報

## GitHub Pages での公開手順

1. このフォルダの内容をリポジトリのルートに push する(`index.html` が直下にあること)
2. GitHub のリポジトリ画面 → **Settings → Pages**
3. **Build and deployment** の Source を **Deploy from a branch** にする
4. Branch: `main` / フォルダ: `/ (root)` を選択して **Save**
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

※ `.nojekyll` は Jekyll ビルドをスキップさせるためのファイルです(そのまま置いてください)。

## ローカルでの確認

`index.html` をブラウザで開くだけで動作します。
